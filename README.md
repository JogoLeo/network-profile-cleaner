# Windows 网络配置清理工具

手机 USB 共享、连过的热点、插过的网线 —— Windows 会为每个网络环境记住一条配置。
用得久了，「网络 2」「网络 3」能一路涨到几十上百条，在网络列表里翻半天也找不到有用的那条。

这个工具把它们**带序号**列出来，输入 `1-10` 或 `1,5-10` 就能批量删掉。

不需要打开注册表，也不需要一个个点开 GUID 看名字。

```
    #  网络名称                  类型    最后连接          GUID
  --------------------------------------------------------------------------
     1  网络                      以太网  2026-08-15 11:04  A1B2C3D4
     2  网络 2                    以太网  2026-08-31 08:49  E5F6A7B8
     3  网络 3                    以太网  2026-09-01 09:49  C9D0E1F2
    ...
    75  网络 75                   以太网  2026-11-05 14:18  3A4B5C6D  <== 当前使用（锁定）
```

---

## 为什么会有这么多

Windows 在 `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\NetworkList\Profiles`
下为每个网络环境存一条记录。识别「是不是同一个网络」靠的是**网络签名** ——
网关 MAC、网卡特征、DNS 后缀等算出来的指纹。

签名变了，Windows 就认为你连上了一个新网络，于是新建一条配置，
名字取当前最小的未占用编号，于是就有了「网络 2」「网络 3」……

常见触发场景：

- 手机的 USB 网络共享，每次开启时网卡 MAC 不同（部分 Android 机型的隐私策略）
- 笔记本在多个 Wi-Fi 之间来回切换，同名不同 MAC 的热点
- 虚拟网卡、VPN、Docker 反复创建销毁

一旦签名固定不下来，这个编号就会一直涨。

## 文件说明

| 文件 | 用途 |
|---|---|
| `一键清理网络配置.bat` | **双击运行**。列出所有网络配置，按序号批量删除 |
| `一键恢复网络配置.bat` | 误删后从快照补回来 |
| `Clear-NetworkProfiles.ps1` | 清理主脚本 |
| `Restore-NetworkProfiles.ps1` | 恢复脚本 |

两个 `.bat` 会自动请求管理员权限，UAC 弹窗点「是」即可。

## 使用

### 清理

1. 双击 `一键清理网络配置.bat`
2. 选择范围：`e` 以太网类（USB 共享 / 有线的「网络 N」都在这）、`w` Wi-Fi 类、`a` 全部
3. 在 `序号` 提示后输入要删的项：

| 输入 | 含义 |
|---|---|
| `7` | 只删第 7 项 |
| `1-10` | 删第 1 到第 10 项 |
| `1,5-10,20` | 混合：第 1、5~10、20 项 |
| `all` | 该分类下全部（当前在用的自动排除） |

4. 会列出待删清单和关联签名数量，输入 `y` 才真正执行
5. 删除前自动备份

### 恢复

1. 双击 `一键恢复网络配置.bat`
2. 列出可用快照（含时间与条目数），选序号
3. 只补齐当前缺失的项，**不覆盖**现有配置
4. 输入 `y` 执行

## 安全设计

删除注册表属于不可逆操作，所以做了三层保护：

**当前网络锁定**
通过 `Get-NetConnectionProfile` 拿到正在使用的网络名，即使输入了它的序号也会自动跳过。
删掉活动配置会立刻断网，并且网络会被重新识别为「未识别的网络」。

**删前自动备份**
用 .NET `RegistryKey` 递归复制整棵 `NetworkList` 树到
`HKCU\Software\_NetworkListBackup\<yyyyMMdd-HHmmss>`，保留最近 5 份。
不依赖 `reg.exe`，所以不会因为系统策略限制而备份失败。

如果 `reg.exe` 可用，还会额外导出一份 `backup\NetworkList-*.reg`，方便手动回滚。

**签名同步清理**
`Profiles` 和 `Signatures` 是一一对应的两张表。
只删 `Profiles` 会留下悬空的签名条目，所以会同时清理 `ProfileGuid` 指向被删网络的签名。

> `backup\` 目录包含完整的本机网络信息，已在 `.gitignore` 中排除。

## 手动恢复

不想用脚本时：

```powershell
# 管理员 PowerShell，先看有哪些快照
Get-ChildItem 'HKCU:\Software\_NetworkListBackup'

# 把某个快照下的 Profiles\<GUID> 复制回
# HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\NetworkList\Profiles\<GUID>
```

如果生成了 `backup\*.reg`，双击导入可恢复整棵 `NetworkList` 树
（注意：这会**覆盖**当前全部网络配置）。

## 它不做什么

- **不能阻止编号继续增长**。清理只解决存量。如果手机端每次开共享都换 MAC，
  Windows 还是会继续新建配置 —— 这是系统行为，不是注册表能修的。
  删掉的编号会被复用，所以不会无限膨胀，隔一段时间跑一次即可。
- **不改动网络连通性设置**。只删历史记录，不碰 IP、DNS、防火墙规则。
- **不适用于域环境下的托管网络**。`Signatures\Managed` 部分由组策略管理，删了可能被策略重新下发。
